# 🏨 Agoda Scraper

Agoda Scraper is a **free and open-source** scraper that gets you **unlimited** detailed Agoda data for free.

## ✨ What Can I Get?

- 🏨 **Full details on 6M+ hotels & homes** — every room with live rates, guest scores, facilities, policies & photos
- 🔍 **Live prices in 7,600 destinations** — search any city, area or landmark with 12 filters & 5 sort orders
- ⭐ **Guest reviews in 35 languages** — Agoda & Booking.com: scores, full text, pros & cons, topics & hotel replies
- 📍 **Autocomplete in 50 locales** — cities, areas, landmarks & hotels with hotel counts & a ready search key

## 🚀 Unlimited Free Agoda Data — Get It in 60 Seconds

1️⃣ Clone and install:
```bash
git clone https://github.com/omkarcloud/agoda-scraper
cd agoda-scraper
python -m pip install -r requirements.txt
```

2️⃣ Start the API:
```bash
python run.py
```

3️⃣ Get your first data:
```bash
curl "http://localhost:8000/hotels/details?hotel=185945"
```

All 4 endpoints are now live at `http://localhost:8000`.

No proxy needed — Agoda served every endpoint to a home connection and a cloud server alike. If you ever see 502 "blocked" errors at high volume, set `AGODA_PROXY` (`AGODA_PROXY=http://user:pass@host:port python run.py`).

## 📚 Endpoints

4 endpoints cover everything you need.

| Endpoint | Path | Returns |
|---|---|---|
| Hotel Details | `/hotels/details` | Every room with live rates, scores, facilities, policies and photos |
| Autocomplete | `/places/autocomplete` | Cities, areas, landmarks and hotels with a ready search key |
| Search Hotels | `/hotels/search` | 45 properties per page with live prices, stars and scores |
| Hotel Reviews | `/hotels/reviews` | Agoda and Booking.com reviews, 20 per page, filterable by topic |
